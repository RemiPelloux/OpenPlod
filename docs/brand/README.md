# OpenPlod Brand Assets

The OpenPlod mark combines an open circular enclosure with a three-bar audio signal. The enclosure represents retained audio; the opening represents export and interoperability. This is original, editable vector artwork, not a Plaud trademark or a device compatibility certification.

- `openplod-mark.svg`: transparent blue mark for light or dark documentation.
- `openplod-icon.svg`: dark application icon with a white enclosure and blue signal.
- `openplod-icon.png`: 1024 px raster master derived from the vector.
- `social-preview.png`: 1280 x 640 repository sharing image.

Use the SVG for resizing. Preserve its proportions and clear space. Do not add gradients, shadows, additional waveform bars, or a Plaud wordmark. The app uses a raster derivative for platform icon generation and the original SVG for its navigation mark.

Palette: signal blue `#3975EE`, dark surface `#111113`, white `#FAFAFA`, bright blue `#5A8FFF`. Typography follows the app's system sans-serif stack.
